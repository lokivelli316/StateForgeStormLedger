# Privacy and Secrets

This repository is a public replication kit. It must contain none of the originating operator's private data.

## Hard rules

Never commit:

- personal manuscripts or private project files
- real personal names, addresses, phone numbers, or family references
- private repository names that are not already public
- personal Drive / cloud object IDs
- real file hashes from private work
- private weekly ledger entries or receipts
- personal model-seat or conversation history
- real unpublished claims or internal research status
- API keys, tokens, cookies, authorization headers, or passwords

## What is allowed

- fictional identities and projects
- synthetic hashes and commit IDs used only for examples
- placeholder credential names such as `GITHUB_TOKEN` or `GOOGLE_CLIENT_ID`
- generic account names (`Human Operator`, `Project Alpha`, `Assistant A`)

## Operator responsibility

If you fork or extend this kit:

1. Keep your real ledger data in a separate private repository or local custody.
2. Never paste live secrets into the browser app or into example files.
3. Export your own snapshots; do not treat the public starter as a place to store private inventory.

The public kit exists to transfer the method, not the private history of any one person.
