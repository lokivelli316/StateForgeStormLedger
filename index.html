Start Here

This is a standalone browser ledger. Everything stays in your browser unless you export it.

  1. Create accounts for yourself, your project, and any assistant that materially acts.
  2. Register existing local files as assets (they enter as LOCAL_PENDING_IMPORT).
  3. Post transactions for meaningful changes: BUILD, CHALLENGE, VERIFICATION, CORRECTION, MERGE, PUBLICATION, ROLLBACK.
  4. Run Reconciliation. It only diagnoses — it never auto-repairs.
  5. Review Trial Balance, then export a JSON or HTML snapshot for durable custody.

Rules that never change: VERIFIED ≠ DISCOVERED. PUBLISHED ≠ VERIFIED. Model agreement is not proof. FAIL does not erase the claim. SUPERSEDED does not erase the predecessor. UNKNOWN cannot silently become PASS.

Read LEDGER_CONTRACT.md before letting any assistant touch your records.
